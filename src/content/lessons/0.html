The one sentence to hold
.NET is the platform. C# is a language that targets it. .NET is not "a C# framework" — it is the runtime, the standard library and the tooling, and C# is the main (but not only) language that compiles to it.

1. The Two Halves

Almost every beginner confusion about .NET comes from collapsing two separate things into one word. Keep them apart:

ThingWhat it is
C#A language. Syntax, type system, rules. It compiles to an intermediate form, not to machine code
.NETThe platform the compiled output runs on: the runtime (CLR), the standard library, the SDK and the package ecosystem

The proof that they are separable: F# and Visual Basic .NET are different languages that compile to the same intermediate form and run on the same runtime, using the same libraries. If .NET were "a C# framework" that would be impossible.

2. What Happens When You Run C#

Two compilation steps, not one. This explains most of .NET's behaviour, including why it is cross-platform and why startup has a warm-up cost.

Program.cs  ——roslyn——▸  IL (in a .dll)  ——CLR/JIT——▸  machine code, running
 (source)                     (portable bytecode)              (specific to this CPU and OS)
  • Roslyn is the C# compiler. It produces IL (Intermediate Language) — a portable instruction set, not x86 or ARM.
  • The CLR (Common Language Runtime) loads that IL and JIT-compiles it to native code the first time each method runs, then caches the result.
  • The CLR also provides garbage collection, type safety, exception handling and threading.

Because IL is portable, the same .dll runs on Windows, Linux and macOS. Because JIT happens at runtime, the compiler knows exactly which CPU it is targeting and can optimise for it — which is why long-running .NET services are fast, and why the very first request is slower than the thousandth.

Coming from Java?
The mapping is almost exact. CLR ↔ JVM. IL ↔ bytecode. C# ↔ Java the language. Base Class Library ↔ the JDK standard library. NuGet ↔ Maven Central. The dotnet CLI ↔ JDK plus Maven in one tool. ASP.NET Core ↔ Spring Boot. Entity Framework Core ↔ Hibernate/JPA.

3. The Naming Mess, Explained Once

Three different naming schemes for one lineage. This is the single most confusing thing about the ecosystem, and it is purely historical:

NameYearsWhat you need to know
.NET Framework 1.0–4.82002–2019Windows only. Legacy — still maintained, still running in enterprises, but no new versions. This is the one with "Framework" in the name
.NET Core 1.0–3.12016–2019A cross-platform rewrite. Open source, much faster. Superseded
.NET 5, 6, 7, 8, 9, 10…2020–Both suffixes dropped. One product, annual releases, even numbers are LTS. This is what you use today

They skipped .NET 4 to avoid confusion with .NET Framework 4.x — which tells you how aware they were of the problem.

Why this matters practically
When you search for help, results span all three eras and the APIs differ. A 2015 Stack Overflow answer about HttpContext.Current or Global.asax is .NET Framework and will not apply. Check the date and the version on anything you read.

5. Where C# Actually Gets Used

  • Enterprise back ends — banking, insurance, logistics, government. Often alongside or instead of Java, and for the same reasons: stability, tooling, long support windows, a large hiring pool.
  • Game development — Unity's scripting language is C#, which is a large share of all C# written.
  • Windows and Microsoft-stack shops — anywhere Azure, SQL Server and Active Directory are already in place.
  • Cloud services — ASP.NET Core is genuinely one of the fastest mainstream web stacks by throughput.

6. How To Use This Course

The structure is deliberate, and it is built around one finding: re-reading feels productive and barely works. Retrieval does.

  • Each page opens with a recall prompt. Answer it from memory before reading. Getting it wrong is part of the mechanism.
  • The right panel has three tabs. Quiz tests recognition, Challenge tests production, Interview tests explanation. Explanation is the hardest and the most revealing.
  • Each page ends with a self-check. If you cannot explain an item without notes, you have not learned it yet — regardless of how familiar it felt while reading.
  • Mark complete only after the self-check. That is what puts a section into the spaced-repetition schedule.
  • The Review Center resurfaces material after 1 day, then 3, 7, 21, 60. Each successful recall widens the gap; a failure resets it to one day.
Type the code out
Every example is short enough to type and run. Copying teaches nothing; typing surfaces the small things you did not actually know — which is the entire point.
